TommyRootDNS v1.5 validation
============================

Version
- versionCode: 6
- versionName: 1.5.0
- minSdk: 24
- targetSdk: 28 (intentional sideload/root compatibility target)

Changes validated
- Root resolver starts localhost:53 bridge before requiring an Android netId.
- Resolver discovers netId via ConnectivityManager then Android 7 dumpsys connectivity.
- Default interface discovery uses /proc/net/route with ip route fallback.
- Resolver strategy order: setnetdns -> legacy setifdns/setdefaultif -> net.dns property fallback.
- net.dns fallback bumps net.dnschange and sends CLEAR_DNS_CACHE broadcast.
- Resolver backup/restore includes strategy, interface, DNS props and dnschange.
- Restore is guarded by an explicit backup marker to avoid clearing DNS on a fresh start.
- VPN is skipped only when /dev/tun is absent and readable /proc/misc positively contains no TUN driver.

Static checks
- Java source compile-check against local Android API-shape stubs: PASS
  (javac source/target 8; only expected deprecation/obsolete source-level warnings)
- AndroidManifest/res XML parse: PASS
- GitHub Actions YAML parse: PASS

DNS53 bridge smoke test
- UDP 127.0.0.1:53 -> 127.0.0.1:5454: PASS
- TCP 127.0.0.1:53 -> 127.0.0.1:5454: PASS

Runtime note
- Full Android Gradle APK build and VPhoneGaGa runtime behavior must still be validated by GitHub Actions + the target Android 7 virtual environment.
- v1.5 specifically targets the observed VPhoneGaGa state where net.dns1/net.dns2 exist but ConnectivityManager reports no active netId, while netfilter and TUN are unavailable.
